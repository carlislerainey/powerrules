# Package index

## Source functions

- [`from_sd()`](https://carlislerainey.github.io/powerrules/reference/from_sd.md)
  : Create a power source from a reference population SD
- [`from_existing()`](https://carlislerainey.github.io/powerrules/reference/from_existing.md)
  : Create a power source from an existing study
- [`from_pilot()`](https://carlislerainey.github.io/powerrules/reference/from_pilot.md)
  : Create a power source from pilot data

## Goal functions

Compute MDE, power, or required sample size.

- [`find_mde()`](https://carlislerainey.github.io/powerrules/reference/find_mde.md)
  : Find the minimum detectable effect
- [`find_power()`](https://carlislerainey.github.io/powerrules/reference/find_power.md)
  : Find the power for a given effect
- [`find_n()`](https://carlislerainey.github.io/powerrules/reference/find_n.md)
  : Find the required sample size
