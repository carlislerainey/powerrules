# powerrules: Power Rules for Balanced Between-Subjects Designs

Implements the rules from Rainey (2026) "Power Rules: Practical Advice
for Computing Statistical Power" and its companion paper "Automating
Power Analysis with Pilot Data" for balanced, between-subjects designs.
Provides a pipeline interface (from\_\*() \|\> find\_\*()) for computing
minimum detectable effects, power, and required sample sizes, with
manuscript-ready output sentences.
